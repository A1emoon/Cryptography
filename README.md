# Криптографический калькулятор для iPhone

Семь заданий: произведение по модулю, двоичное деление с остатком, обращение по модулю, деление по модулю, удвоение–сложение для многочленов, алгоритмы Чиполлы и Берлекэмпа–Рабина. Полные учебные решения на русском языке с точными целыми числами произвольной длины; для простого модуля в алгоритмах Чиполлы и Берлекэмпа–Рабина действует граница 2⁶⁴−1.

## Открыть и запустить

1. Откройте `NumberTheory.xcodeproj` в Xcode. Для iPhone-приложения открывайте именно проект, а не `Package.swift`.
2. Выберите схему **NumberTheory** и симулятор iPhone в верхней панели.
3. Нажмите **Run** (`⌘R`). На главном экране выберите карточку задания. На каждой карточке есть название, формула и пример ответа.
4. Над полями указана формула с расшифровкой букв. Измените входные значения и нажмите **Решить**. Перед ходом решения повторяется формула с вашими числами. Таблицы, длинные формулы и цепочки прокручиваются горизонтально. Кнопка **Об алгоритме** открывает описание. Переключатель **Пояснения** скрывает дополнительные пояснения; арифметические действия остаются видимыми.

У первых пяти заданий есть переключатель **Подробно / Как в конспекте**. Первый режим сохраняет полный ход решения. Второй показывает математическую запись по присланным образцам: цепочки перевода в двоичную систему, таблицы, цепочки дробей или матриц, необходимые условия и ответ. В нём нет вспомогательных проверок НОД для существующего обратного, поясняющих разделов и повторной арифметики под матрицами. Для многочленов остаются векторы и вычисления в таблице; отдельная подготовка верхней строки и сырые разности коэффициентов скрыты. Выбор режима запоминается отдельно для каждого задания, пересчёт при переключении не требуется.

Примеры по умолчанию: `(78 · 96) mod 273 = 117`, `1530 = 41 · 37 + 13`, `113⁻¹ mod 512 = 145`, `(153 / 179) mod 283 = 72`, `(α² + 2α + 1)(2α³ + α + 3) mod (α⁴ + 2α + 2, 5) = 3α³ + α²`, `x² ≡ 29 (mod 109) ⇒ x ≡ 47, 62`.

Для своего iPhone: в настройках проекта выберите target **NumberTheory → Signing & Capabilities → Team**, укажите свою команду Apple ID и оставьте **Automatically manage signing** включённым. Подключите iPhone, подтвердите доверие, включите Developer Mode при запросе, выберите устройство и нажмите `⌘R`. Если bundle identifier занят вашей другой разработкой, измените `com.alemoon.numbertheory` на уникальный. На физическом iPhone эта версия пока не проверена.

В заданиях **Чиполлы и Берлекэмпа–Рабина** открывается единый лист, как запись студента: условие, проверки, непрерывные равенства, корни и ответ. Переключателя режимов, поясняющих заголовков и встроенных таблиц на нём нет. Кнопка с карандашом открывает ввод. Значок ↗ у выражения ведёт к вспомогательному вычислению степени, умножению или делению уголком; ? объясняет выбранную строку. В пояснениях математические термины открывают определения, есть также словарь. Этот формат пока применяется к этим двум заданиям.

Пример лекции 8: `x³ + 3x² + 2x + 1 ≡ 0 (mod 7)` даёт `[1]₇`. Поддержаны несколько и повторные корни, нулевой корень, нормирование, постоянный/нулевой многочлен, отсутствие корней и отдельный случай q=2. Для разделения используется последовательный перебор δ из лекции; расчёт фоновый и отменяемый.

## Реализовано

- Точная арифметика целых чисел произвольной длины; нет ограничения `Int64` и округлений.
- Десятично-двоичные цепочки обоих множителей с остатками под каждым числом.
- Выбор множителя по числу единиц; при множителе 1 разбирается другое число.
- Столбец с пустой верхней ячейкой и числом 2 внизу.
- Удвоения, сложения, вычитания внутри ячеек; без знаков сравнения.
- Полная вспомогательная таблица, если прибавляемое число сначала нужно привести по модулю.
- Отрицательные множители, ноль, модуль 1, проверка неверного ввода.
- Фоновые вычисления с отменой, светлая/тёмная тема, системный размер текста.
- Главный экран с карточками задач и формулы перед вводом и решением.
- Двоичное деление: двоичные длины с доказательством через степени двойки, цепочка удвоений делителя, выбор показателя `l` или `l − 1`, полные рекуррентные преобразования дробей и сумма степеней двойки.

- Обращение: сокращённый/полный расширенный бинарный алгоритм Евклида, последовательный подъём по степеням двойки, матрица с нулевыми строками для модуля 2ᵏ.
- Деление по модулю: через обратный элемент с полной таблицей умножения либо непосредственно через третью строку. Во втором случае под каждой матрицей показано условие `≤` несобранной части числителя; подходящая строка сразу добавляется к третьей. Большие множители разрешены только при левом элементе 1 или 2.
- При преобразовании рабочих строк деление пополам приоритетно перед вычитанием; отрицательные представители и корректировки коэффициентов видны отдельными шагами. Отдельная проверка существования обратного, итоговая проверка ответа и быстрое открытие ответа с проверкой.

Многочлены вводятся векторами от старшего коэффициента к свободному члену: `1, 2, 1`, `2, 0, 1, 3`, `1, 0, 0, 2, 2`; модуль коэффициентов — `5`. Формула каждого многочлена видна под полем. Поддерживаются отрицательные и произвольно длинные целые коэффициенты. Требуется p ≥ 2 и многочлен M положительной степени со старшим коэффициентом 1 после приведения по p. Решение показывает выбор по весу Хэмминга, подготовку верхней строки, таблицу со сдвигом `(1, 0)`, вычитания кратного M, сложения и приведение коэффициентов. При необходимости второй множитель предварительно приводится по M. Кнопка «Ответ и проверка» открывает отдельную проверку раскрытием скобок.

Алгоритм Чиполлы находит оба квадратных корня по простому модулю. По умолчанию — пример с пары `a=29`, `p=109`: перебор δ=0…4, ω²=−13, показатель 55 и ответ 47, 62. Необязательное поле δ позволяет выбрать другой допустимый вариант. Сохраняются цепочки символов Лежандра/Якоби, таблицы целочисленных произведений, последовательные квадраты и попарное перемножение выбранных степеней. На основном листе есть оба корня, проверка их квадратов и завершение незаконченного примера с доски. Поддерживаются a любой длины, отрицательные числа, нулевой корень, p=2 и отсутствие корней. Здесь p ограничен диапазоном 2…2⁶⁴−1 для точной проверки простоты; составные и большие модули отклоняются явно.

В Чиполле нет переключателя режимов: математическая запись идёт непрерывно, без заголовков этапов и встроенных вспомогательных таблиц. ↗ у символа открывает его вычисление, у двоичной записи — полный перевод, у произведения — раскрытие скобок и коэффициенты. Внутри доступны отдельные таблицы удвоения–сложения. ? объясняет конкретную строку; термины в тексте и словаре открывают определения. Дробные показатели сохраняют исходную формулу: например, степень 756 раскрывается как (108·28)/4. Ввод a, p и необязательного δ открывается карандашом; отмена сохраняет текущее решение. После закрытия вспомогательных окон сохраняется место на листе.

В первом задании модуль должен быть положительным. В делении делитель должен быть ненулевым; для любых знаков входов возвращается евклидов остаток `0 ≤ r < |b|`, восстановление знаков показано отдельно. В обращении и делении по модулю требуется `m > 1` и взаимная простота обращаемого числа/знаменателя с модулем. При невзаимно простых входах выводится доказательство отсутствия обратного, а для дроби — также наличие или отсутствие решений соответствующего сравнения. Все классы решений такого сравнения отдельно не вычисляются. В полях допустимы десятичные цифры и один начальный знак `+`, `-` или `−`; пробелы по краям удаляются. Разделители разрядов, дроби и научная запись не принимаются. Все промежуточные шаги сохраняются, поэтому очень длинные решения требуют соответствующего времени и памяти.

## Проверки

Математическое ядро:

```sh
swift test --scratch-path build/swiftpm --cache-path build/swift-cache --disable-sandbox
```

UI-проверки: в Xcode выберите схему **NumberTheory**, симулятор iPhone и нажмите `⌘U`.

Эталонные большие числа вычислены независимо через встроенную арифметику Python. Обновить эталоны: `python3 Scripts/generate-fixtures.py`, `python3 Scripts/generate-division-fixtures.py` и `python3 Scripts/generate-modular-fixtures.py`.

## Структура проекта

```text
App/
  Application/                  # запуск и выбор задания
  Features/
    Doubling/                   # удвоение–сложение
    BinaryDivision/             # двоичное деление
    ModularArithmetic/          # обращение и деление по модулю
    Polynomials/                # многочлены
    Cipolla/                    # алгоритм Чиполлы
    BerlekampRabin/              # корни многочленов
  Shared/
    Components/                 # общие элементы интерфейса
    Math/                       # формулы, скобки и таблицы
    Notebook/                   # оформление конспекта
    Theme/                      # цвета и шрифты
    StudentSolution/            # единая математическая запись и окна
  Resources/                    # каталог ресурсов и исходник иконки
Sources/NumberTheoryCore/
  Arithmetic/                   # точные целые числа
  Algorithms/                   # алгоритмы и данные решения
Tests/NumberTheoryCoreTests/
  Algorithms/                   # проверки алгоритмов
  Fixtures/                     # независимые эталоны
UITests/                        # сценарии интерфейса
Documentation/
  ARCHITECTURE.md               # устройство приложения
  MATH_SPEC.md                  # математические правила
  PROJECT_STATUS.md             # требования и результаты проверок
  Screenshots/                  # проверенные скриншоты
  References/                   # страницы конспектов
Scripts/                        # проект Xcode, иконка и эталоны
```

Такая же иерархия показана в навигаторе Xcode. Документация: [архитектура](Documentation/ARCHITECTURE.md), [математические правила](Documentation/MATH_SPEC.md), [состояние проекта](Documentation/PROJECT_STATUS.md).

Проект Xcode готов к открытию. После добавления новых исходников обновите его командой `python3 Scripts/create-xcode-project.py`: поиск файлов рекурсивный, группы создаются по папкам. Генератор сохраняет существующие настройки сборки, Team, bundle identifier и общую схему запуска.

Иконка — калькулятор со знаком сравнения по модулю и криптографическим щитом. Редактируемый исходник: `App/Resources/AppIconSource.svg`. Готовый непрозрачный PNG 1024×1024 находится в `App/Resources/Assets.xcassets/AppIcon.appiconset/`. Для повторного рендера: `node Scripts/create-icon.cjs` (нужны Node.js и Sharp; для сборки приложения они не требуются).
