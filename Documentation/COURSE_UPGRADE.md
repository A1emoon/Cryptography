## Исправления и уточнения

- Отделены ℓ(m) из конспекта (НОК φ простых степеней) и функция Кармайкла λ(m); для 2ᵏ их значения могут различаться.
- Рост порядка при подъёме без дальнейшей проверки обоснован для нечётных простых; для 2 каждый подъём проверяется отдельно.
- В кубическом алгоритме показатель (kr+1)/3 целый: k=1 или 2 в зависимости от r по 3; не используется ошибочное универсальное (r+1)/3.
- Критерий Якоби=1 не объявляется достаточным по составному модулю.
- В вероятностной оценке Рабина указаны условия: квадратсвободный, полностью линейно разложимый многочлен степени не меньше 2 и случайный выбор сдвига.
- У утверждений о четырёх нечётных корнях по 2ᵏ указано k≥3; при подъёме сдвиг равен 2ᵏ⁻¹.
- Точные константы битовой сложности сопровождаются моделью стоимости; не смешиваются с асимптотическими оценками.
- Полиномиальный метод с делением на α требует M(0)≠0; иначе применяется метод старшего члена.
