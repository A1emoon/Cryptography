## Математическая запись

Для n=2,3 после проверки разрешимости записываем p−1=nˢr, n∤r. В квадратном случае критерий и поиск невычета оформляются полной цепочкой символа Лежандра; взаимность, выделение двоек и вычисление знаков видны на основном листе. В кубическом случае используется степень a^((p−1)/3).

Вычисляем aʳ, затем его порядок последовательными n-ми степенями. k используется в форме **(aʳ)^(n·k)=1**; k равен порядку aʳ, делённому на n. Старый коэффициент k=1/2 для обратного к r убран из записи. На фото значения k и записи 3k/3^k местами смешаны; приложение выдаёт согласованные равенства: для a=13,17 по 163 порядок a² равен 27, поэтому k=9; для a=267 по 487 порядок a² равен 9, поэтому k=3.

Автоматически выбираем первый n-й невычет b и обозначаем B=b^((p−1)/n). Bⁿ=1, B≠1. В кубическом случае явно считаем B² и B³. Дальше сохраняем исходные основания a,b и формальные показатели в равенствах; α, ε и счётчик c в основном решении отсутствуют.

Для внутреннего выражения Y=aᴬbᶜ, удовлетворяющего Yⁿ=1, вычисляем Y∈{1,B,…,B^(n−1)}. Выбираем j так, чтобы YBʲ=1. Подставляем B как степень b, складываем показатели и только после получения 1 выносим общую n-ю степень. На следующем уровне Y вычисляется заново: из Yⁿ=1 нельзя заключать Y=1.

После aʳbᶜ=1 домножаем на a=xⁿ и выделяем n-ю степень. Для кубического случая r≡1 mod3 перед этим явно возводим равенство в квадрат. После получения x₁ перечисляем −x₁ для квадрата или x₁B,x₁B² для куба. Ответы проверяются независимой подстановкой и сортируются по неотрицательным представителям.

Для x³≡3 mod73 фотография использует равенство 3⁸·2¹²≡1 и выбирает x₁=67. В приложении единая подстановка B²=(2²⁴)²=2⁴⁸ выбирает x₁=25; это другой корень из того же полного множества. Оба равенства верны, поскольку 2³⁶≡1. Извлечение кубического корня из 1 не является однозначным, поэтому порядок перечисления x₁,x₂,x₃ может различаться. На фото для b встречается квадратный показатель 36; для кубического невычета в проверке используется правильный показатель 24.

В квадратном примере 5 mod41 Markdown заменил исходную степень 3¹⁵ на 3³ и тем самым выбрал другой первый корень. Реализация сохраняет равенство 5⁵·3³⁰≡1 с фотографии. В кубическом примере 13 mod163 в Markdown пропущено понижение внешних степеней; оно восстановлено по фото. Все перестановки корней и исправления касаются записи, а не множества решений.

## Общая реализация

`TonelliShanksSolver` хранит степени и каждое понижение как точный след. `TonelliLecture` строит единую математическую запись, ссылки и причины переходов. `TonelliLectureView` отображает её одинаково на iPhone и Apple Watch, сохраняя горизонтальную прокрутку часов. Обе формы ввода используют один набор `TonelliLectureExample` с семью примерами. Описание алгоритма доступно через существующую кнопку помощи.

Расширения: ноль; простой модуль 2 или 3; отсутствие корней; единственный кубический корень при НОД(3,p−1)=1; случай r≡1 mod3; отрицательные и длинные правые части; отмена расчёта. Формальный показатель 2C хранится без потери точности, даже если превосходит 2⁶⁴−1; для числового вычисления деление выполняется до умножения.

Дальнейшие изменения математических алгоритмов выполняются сразу для iPhone и Apple Watch; после изменения общей записи проверяются обе платформы.

## Полный студенческий лист без скрытых основных шагов

По уточнению пользователя основной лист — последовательное решение, которое можно целиком переписать без открытия дополнительных окон. Теперь видны:

- последовательные квадраты, их числовые значения и остатки;
- разложение каждого нужного показателя в сумму степеней двойки, подстановка ранее вычисленных степеней и последовательные произведения;
- вся цепочка символа Лежандра: взаимность, дробный и числовой показатели (−1), переход к следующему символу и итоговый знак;
- все проверки порядка aʳ, из которых получается k;
- подстановка B, раскрытие степени степени, сложение показателей, деление показателей при вынесении общей степени;
- подстановка вычисленных степеней в корни и числовые результаты произведений.

Например, для 17 mod163 на листе непосредственно записаны 17²=289≡−37, 17⁴≡(−37)²=1369≡65, 17⁸≡65²=4225≡−13, 17¹⁶≡(−13)²=169≡6, 17³²≡6²=36 и цепочка 17⁵⁴=17²·17⁴·17¹⁶·17³²≡(−37)·65·6·36≡40·6·36≡77·36≡1.

Отдельное окно открывает только таблицу удвоения–сложения для произведения. Тип `TonelliLectureWork` допускает только `product`: скрыть за ним степень, символ Лежандра или объединение показателей теперь нельзя. Уже вычисленная степень может повторно использоваться по ранее написанной строке, а не по скрытой ссылке.
