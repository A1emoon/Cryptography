## Существенные исправления

Исправления видны в соответствующих статьях, а не скрыты под видом буквального воспроизведения преподавателя.

1. **№1, число операций египетского умножения.** При пропуске прибавлений нуля и без начального присваивания точное число — m+w₂(a)−2. Для множителя, равного степени двойки, это m−1. Поэтому нижнюю лекционную границу m нельзя переносить на него без оговорки о способе счёта.
2. **№4, битовые оценки египетского умножения.** Сохранены разные модели первой и второй лекций, указано, сколько стоит сдвиг, сложение и присваивание. В модели второй лекции исправлены конечные суммы: E₋=(3m²−3m+2)/2, E₊=4m²−6m+3. Для m≥2: m²≤BT<4m²; нижнее строгое неравенство требует m>2. Случай m=2 отдельно не потерян.
3. **№5, двоичное деление.** Указана модель худшего полного расписания длин nⱼ=n−j+1 и построения сдвигов исходного делителя. Нижняя сумма — не универсальная оценка каждого входа с пропуском нулевых разрядов. Восстановлены начальная стоимость n+k и точные линейные члены: S₋=D₋k²+(5α+7)k/2, S₊=(D₋+α−1)k²+(5α+9)k/2. При k>13 они дают лекционные коэффициенты D₋=3α²/2+α−5/2, D₊=3α²/2+2α−5/2. Допускается α=2.
4. **№6, наивное произведение с остатком.** При равных длинах множителей t точное соотношение — t=⌈ℓ₂(ab)/2⌉. Для длины произведения n верно n≤2k, не обязательно n<2k. Сохранены конечные линейные члены до последнего поглощения в квадратичную оценку. Как и №5, оценка относится к указанному лекционному худшему расписанию деления.
5. **№7, удвоение–сложение.** Для полного k-битного прохода ровно k−1 итераций, поэтому суммы равны 2k²−k и 6k²−5k. Короткие множители, 0 и 1 могут требовать меньше работы; нижняя квадратичная оценка не утверждается для каждого такого входа.
6. **№10, рост порядков.** Условие нечётности простого q существенно; при q=2 порядок может перестать расти на следующем уровне. Например, для 3 по модулям 2,4,8 порядки равны 1,2,2.
7. **№18, L(m) и λ(m).** Утверждение о существовании элемента порядка L(m) вообще неверно: L(24)=4, но все обратимые классы по 24 имеют квадрат 1 и λ(24)=2. Верная теорема о достижении универсального показателя сформулирована через функцию Кармайкла λ. Контрпример и исправление отмечены в статье.
8. **Определения логарифма и степенного вычета, №19–20,28.** Логарифм по основанию a определён только для элементов подгруппы ⟨a⟩. Критерии через порядок относятся к ненулевым элементам. Ноль может быть степенным вычетом, но не имеет мультипликативного порядка; восстановление всех корней умножением на корни из единицы требует ненулевого исходного корня.
9. **№32, вероятность Берлекэмпа–Рабина.** По рукописи и сводному доказательству верный знак — **плюс**: 1/2+3/(2q). Для строгой версии границы в условие включена предварительная проверка линейного делителя X+δ (параметр может равняться минус одному из корней). Затем используется НОД с (X+δ)^((q−1)/2)−1. Многочлен разности имеет степень (q−3)/2, откуда не меньше (q+3)/2 хороших параметров. Эта теорема описывает именно названную версию шага; существующий вычислитель задач не изменялся и перебирает сдвиги последовательно, поэтому случайная вероятность к его трассе не приписывается.
10. **№33–36, корни по степени двойки.** Во всех формулах сохранены нечётность a и нужные границы k. При переходе 2ᵏ→2ᵏ⁺¹ выбор производится между x и x+2ᵏ⁻¹; это другой сдвиг, чем прибавление половины нового модуля при восстановлении остальных корней.

Общие арифметические уточнения (кольцо вместо поля при составном модуле, условия моничности и обратимости) сохранены в определениях. Формулы в сводном PDF, не совпавшие с рукописью, не копировались автоматически.
