# Математическая спецификация

Первый раздел описывает удвоение–сложение. Двоичное деление описано отдельным разделом ниже.

## Задача

Для целых `a`, `b` и положительного целого `m` вычислить единственный `r`, для которого `0 ≤ r < m` и `r ≡ ab (mod m)`. Ответ всегда неотрицательный. Модуль 0 и отрицательные модули отклоняются.

## Двоичные записи и выбор

Для отрицательного входа переводится его абсолютное значение, что явно показано в решении. Каждое целое частное при делении на 2 и остаток сохраняются. Цепочка заканчивается 1; для исходного 0 отображается единственная запись 0 с остатком 0. Двоичные цифры читаются в обратном порядке.

Обычный выбор: меньше единиц, затем меньше двоичных разрядов, затем первый множитель. Это сокращает число ненулевых сложений, но не является универсальной минимизацией всех операций для разных длин записей. Если модуль одного множителя равен 1, разбираем двоичную запись другого числа: учебный способ нахождения остатка.

## Таблица

Обозначим выбранное число `n`, прибавляемое число `c`. Обрабатываем двоичные цифры `n` слева направо. В верхней строке стоит `c` для 1 и 0 для 0. В первом столбце верх пуст, низ равен 2. При первом старшем разряде 1 начальный остаток равен `c`.

Для каждой последующей цифры `d`:

1. `t = 2r`.
2. Если `t ≥ m`, записать `t − m` и заменить `t` результатом.
3. `u = t + d·c`, в том числе явное сложение с 0.
4. Если `u ≥ m`, записать `u − m`.
5. Полученное значение — следующий остаток.

В интерфейсе знаки сравнения не показываются: только реальные операции. В частности, равенство модулю требует вычитания.

Инвариант: после каждого столбца `r ≡ prefix·c (mod m)`, где `prefix` — уже прочитанный двоичный префикс. Переход `prefix' = 2·prefix + d` доказывает корректность следующего столбца. При `0 ≤ r,c < m` удвоение и сложение не достигают `2m`, поэтому каждой фазе достаточно одного вычитания.

## Большое прибавляемое число

Исходные числа не заменяются остатками до двоичного перевода и выбора. Если выбранное прибавляемое `c ≥ m`, выполняется отдельная полная таблица `(c · 1) mod m` по уже имеющейся двоичной записи `c`. В ней прибавляемое равно 1; поскольку ветка `m=1` обработана отдельно, выполнено `1 < m`.

Получаем `c₀`, явно записываем `c ≡ c₀ (mod m)`, затем проводим основную таблицу с `c₀`. Правомерность следует из `n·c ≡ n·c₀ (mod m)`. Это сохраняет все шаги, не требует готового оператора `%` для больших чисел и избегает огромного числа последовательных вычитаний `m`. Вспомогательная таблица — правило реализации для случая, образец оформления которого преподаватель ещё не предоставлял.

## Знаки и особые случаи

- Если `a=0` или `b=0`, ответ 0; показаны двоичные цепочки и объяснение.
- Если `m=1`, ответ 0; показаны двоичные цепочки и объяснение.
- Для отрицательных входов сначала решается задача для абсолютных значений.
- Если знаки различны и остаток `s` ненулевой, ответ `m−s` с явным действием.
- При `s=0` ответ остаётся 0; при двух отрицательных входах поправка не нужна.

## Представление чисел и трудоёмкость

`Natural` хранит неотрицательное число в массиве разрядов по основанию `10^9`, начиная с младшего. Ноль — пустой массив. Для временных переносов используется `UInt64`; сложение двух разрядов с переносом не превышает `1 999 999 999`. Деление на 2, сравнение, сложение и вычитание выполняются точно.

Пусть `B` — число двоичных разрядов, `L` — число машинных разрядов большого числа. Преобразование и проход по таблице требуют порядка `O(BL)` работы; полный сохранённый след может занимать `O(BL)` памяти. Верхняя числовая граница в коде не установлена, но ресурсы устройства конечны. Отмена проверяется между шагами. Один примитивный проход по массиву разрядов не прерывается посередине.

## Двоичное деление уголком: сумма степеней двойки

Источник оформления — конспект пользователя от 15 октября 2026 года, пример `1530 : 41`. Это версия деления, в которой частное строится суммой степеней двойки, а в рекуррентных дробях остаются десятичные числа.

Вход: целые `a`, `b`, `b ≠ 0`. Ответ: целое `q` и единственное `r` с `a = bq + r`, `0 ≤ r < |b|`. Сначала алгоритм работает для `A = |a|`, `B = |b|`, затем явно восстанавливает знаки. При положительном делителе `q = floor(a/b)`; при отрицательном эта формула не является принятой конвенцией.

Для положительного `n`: `l₂(n)=L` тогда и только тогда, когда `2^(L−1) ≤ n < 2^L`. Длины и границы вычисляются точно удвоением целых чисел. Ноль рассматривается отдельно; в интерфейсе для него не используется логарифмическое определение длины.

Строится цепочка `B, 2B, 4B, ...`, включая первое значение, превышающее `A`. Начальные `R=A`, `Q=0`. Пока `R ≥ B`:

1. `l = l₂(R) − l₂(B)`.
2. Проверить `2^l B`. Если оно не больше `R`, выбрать степень `2^l`, иначе `2^(l−1)`. В решении показываются `l` и `l−1`, без дополнительного буквенного обозначения показателя.
3. Подтвердить, что выбранное кратное не превышает `R`, а следующее удвоение уже превышает его.
4. Вычесть выбранное кратное из `R`, прибавить соответствующую степень двойки к `Q`.
5. Показать рекуррентную формулу `floor(R/B) = floor((R−2^l B)/B) + 2^l` либо ту же формулу с показателем `l−1`, с накопленными ранее степенями, и продолжить с новым остатком.

Границы двоичных длин доказывают, что максимальный подходящий показатель лежит в `{l,l−1}`. При `l=0` и `R≥B` всегда подходит показатель 0, поэтому отрицательный индекс невозможен. Инвариант всех шагов: `A=BQ+R`. После вычитания остаток меньше выбранного кратного, следовательно показатели следующих выбранных степеней строго убывают. Завершение при `R<B` даёт частное и остаток; алгоритм конечен.

В примере: длины 11 и 6; удвоения `41 → 82 → 164 → 328 → 656 → 1312 → 2624`; степени `5,2,0`; вычитания `1530−1312=218`, `218−164=54`, `54−41=13`. Частное `2^5+2^2+2^0=32+4+1=37`. Итог `1530=41·37+13`. В отличие от сокращённой записи на фото, последний переход показан полностью.

Восстановление знаков: если `a<0` и `R>0`, заменить модуль частного на `Q+1`, остаток на `B−R`. В остальных случаях сохранить `Q,R`. Знак ненулевого частного отрицателен при разных знаках входов. Это сохраняет `a=bq+r`. Для `a=0`, `|a|<|b|`, деления на 1 и точного деления предусмотрены полные корректные ответы.

Показатели степеней — индексы массивов, сами числа и степени — `Natural`. Нет машинного деления больших чисел, операций с плавающей точкой и ограничения `Int64`. Цепочки и шаги сохраняются; UI лениво создаёт видимые блоки. Отмена проверяется при построении степеней, удвоений и на каждом вычитании.

Проверки деления: 7050 комбинаций `a ∈ [-70,70]`, `b ∈ [-25,25] \ {0}` с проверкой тождества, границ остатка, жадного выбора и убывания степеней; 128 независимых эталонов Python `divmod`, включая число из 1001 цифры; конкретная трасса преподавателя, ветка с показателем `l−1`, степени двойки, ноль, единица, разные знаки, ошибочный ввод и отмена.

## Обращение и деление по модулю

Статус: реализованы. Вход — знаковые целые числа и модуль m > 1. Отрицательные и большие входы сначала приводятся к остаткам с показом вычитаний. Источники — два PDF-конспекта пользователя и фотографии IMG_0754/0755 и уточнения пользователя от 20 октября 2026 о немедленном накоплении подходящей строки.

При преобразовании рабочих строк допустимое деление пополам имеет приоритет перед вычитанием. В прямом делении по модулю подходящую строку сначала добавляют к третьей и обновляют условие, затем продолжают преобразования рабочих строк. Последовательные деления показывать полностью. Приоритет действует до достижения условия завершения; нулевую строку не делить бесконечно.

Перед отказом от деления проверять эквивалентные представители по модулю, в том числе отрицательные. Отрицательные промежуточные значения разрешены; не приводить каждый коэффициент автоматически к неотрицательному остатку. Переход к выбранному представителю показывать отдельным шагом, затем показывать деление.

Пример из пользовательского оформления: для модуля 283 коэффициент 141 можно заменить на `141 − 283 = −142`. Строка `(52 | 141)` переходит в `(52 | −142)`, затем в `(26 | −71)`. Сохраняется сравнение левого элемента с произведением коэффициента на исходный знаменатель.

Замена представителя не является произвольным изменением знака: `x` заменяется на `x + k·m`. Для нечётного модуля прибавление или вычитание модуля меняет чётность; для чётного модуля чётность сохраняется. В полном расширенном алгоритме каждое преобразование обязано сохранять точное линейное равенство: коэффициенты корректируются согласованно с помощью строк, представляющих ноль. Нельзя переносить правило деления сравнения для нечётного модуля на чётный без проверки условий соответствующего метода.


### Методы и инварианты

1. Для нечётного m сокращённая строка `(r | α)` означает `r ≡ α·a (mod m)`. Если r чётно, коэффициент α тоже должен стать чётным: уже чётный сразу делим; для нечётного вычисляем канонический остаток t и выбираем чётный из t и t−m. Это допускает отрицательные коэффициенты без смены класса вычетов. Деление сравнения на 2 допустимо, поскольку m нечётно.
2. Для общего чётного m используется полная строка `(r | α β)`, `r = α·a + β·m`. При взаимной простоте a нечётно. Перед делением чётного r нечётные коэффициенты корректируются добавлением `(0 | m −a)` или `(0 | −m a)`. Выбирается меньший модуль нового α, при равенстве — первый вариант. Деление затрагивает все три координаты. При отсутствии чётных рабочих строк из большей вычитается меньшая. Достижение единицы завершает обращение.
3. Для m=2ᵏ отдельный матричный метод начинается с `(m | 0 1)` и двух постоянных нулевых строк. На каждом шаге рабочая строка делится пополам, при необходимости после добавления одной нулевой строки. Получаем `(1 | α β)`, следовательно α — обратное.
4. Метод подъёма начинает с x=1 mod 2 для нечётного a. Для очередного модуля 2M кандидат x либо уже даёт произведение с остатком 1, либо заменяется на x+M. Поскольку a нечётно, прибавление M меняет произведение на M по модулю 2M. Сохраняются все k этапов, проверки и прибавления.
5. Прямое деление `u/v mod m` использует нормализованные A=v mod m и U=u mod m. Две рабочие строки стартуют с m и A, третья — нулевая. Под каждой матрицей показывается `≤ T`, где T=U−R₃. Проверять исходную матрицу и результат каждого деления или вычитания: если есть положительная рабочая строка с левым элементом ≤T, сразу добавить её к третьей, до следующего деления. Если подходят обе, выбирать наибольшую. При левом элементе >2 добавляется одна копия строки. Исключение для 1 и 2: разрешено добавить сразу floor(T/r) копий; если для 2 остаётся 1, продолжить делением пополам. После добавления обновить T и продолжить преобразования рабочих строк, не добавлять повторно неизменённую строку и не группировать её копии большими степенями двойки. Деление рабочих строк имеет приоритет перед вычитанием. При T=0 третья строка даёт ответ. Пример 153/179 mod 283: после вычитания сразу добавляется (104 | −1), T=49; после двух делений добавляется (26 | −71), третья строка (130 | −72), T=23; после следующего деления добавляется (13 | 106), третья строка (143 | 34), T=10.
6. Альтернативное деление сначала находит обратное одним из методов 1–4, затем использует полный существующий след удвоения–сложения для произведения числителя и обратного.

В матричных бинарных преобразованиях модуль целого множителя строки не превышает 2 (вычитание — коэффициент −1). Исключение допускается только для добавления к третьей строке при левом элементе рабочей строки 1 или 2.

Перед каждым методом проводится полный бинарный НОД (с отдельным общим множителем 2), также с приоритетом деления. Если НОД не равен 1, вычисление обратного не запускается. Для дроби дополнительно проверяется делимость числителя на НОД: либо сравнение не имеет решений, либо имеет d классов по модулю m. Значение дроби через обратный элемент в обоих случаях не определено; решение общего линейного сравнения не входит в эти две задачи.

Автоматический выбор: для обратного при степени двойки — матрица с нулевыми строками, иначе бинарный Евклид; для дроби — третья строка. Пользователь может выбрать другие методы. Подъём и специальная матрица отклоняют модуль, не являющийся степенью двойки. Модуль 0, 1 и отрицательные модули отклоняются с объяснением. Исходный нулевой/кратный модулю знаменатель приводит к отсутствию обратного.

Проверки: 9 групп тестов модульных методов; эталоны 129⁻¹ mod 257 = 2, 3⁻¹ mod 7 = 5, 113⁻¹ mod 512 = 145, 7⁻¹ mod 16 = 7, 153/179 mod 283 = 72, 5/7 mod 13 = 10, 73/97 mod 357 = 67. Перебор a от −45 до 45, m от 2 до 45, всех применимых методов и пяти числителей проверяет ответы, НОД, каждую строку и приоритет операций. 23 независимых эталона Python включают 1001-значные числа и модуль 2¹⁰²⁴. Проверяются отмена, ошибочный ввод и отсутствие обратного.


### Оформление матриц (уточнение 20 октября 2026)

В методе для модуля 2ᵏ полная матрица с двумя постоянными нулевыми строками показывается один раз в начале. После каждого преобразования отображается только первая рабочая строка. Её левый элемент всегда записывается степенью двойки, включая 2⁰; в начальных нулевых строках коэффициенты ±m также записываются как ±2ᵏ. Начальная цепочка коэффициентов α, равных левому элементу, сохраняет ту же степенную запись; остальные α и все β остаются десятичными, как в образце. В пояснениях к делению первого столбца также показывается переход 2ᵏ : 2 = 2ᵏ⁻¹. Числовые данные всех трёх строк в ядре сохраняются полностью для проверки инвариантов.

В остальных матричных методах показываются все строки каждого состояния. Нижние индексы преобразований M выводятся отдельным элементом с собственной высотой и отступом; они не зависят от нижней границы шрифтового глифа. Обозначения по-прежнему ссылаются на исходные номера строк даже при сокращённом отображении.

## Удвоение–сложение для многочленов (20 октября 2026)

Источник: новый конспект пользователя, `(α²+2α+1)(2α³+α+3) mod (α⁴+2α+2, 5)`.

Векторы отображаются от старшей степени к свободному члену, с обязательными внутренними нулями. Вход — целые коэффициенты через запятую, точку с запятой или пробел; внешние круглые скобки необязательны. Все коэффициенты приводятся в диапазон 0…p−1, p≥2. M после приведения должен иметь положительную степень и старший коэффициент 1. При этих условиях метод работает и для составного p; простота p и неприводимость M не требуются для операции умножения. Немонический M пока отклоняется с объяснением.

Множитель для перебора коэффициентов выбирается по минимальному весу Хэмминга (количество ненулевых коэффициентов после приведения по p), при равенстве — по минимальной степени, затем A. Коэффициенты выбранного множителя не сокращаются по M заранее. Второй множитель при необходимости приводится по M с показом каждого вычитания c·αᵈ·M. Верхняя строка таблицы — произведения каждого коэффициента выбранного множителя на приведённый второй, по модулю p, включая нулевые ячейки. Каждое скалярное произведение раскрывается до таблицы.

Первая нижняя ячейка равна первой верхней. Для каждой следующей: умножить прошлый остаток на α (дописать ноль справа), если степень достигла deg M — вычесть старший коэффициент, умноженный на M, привести разности по p, затем прибавить верхнюю ячейку и привести суммы по p. Степень до сдвига меньше deg M, поэтому в основном цикле достаточно одного вычитания M. Слева в таблице сверху пусто, снизу `(1, 0)`. Сырые суммы/разности и остатки записаны в ячейках столбиком; отрицательные промежуточные коэффициенты не скрываются. Вспомогательные полиномиальные коэффициенты c и aᵢ не ограничены числом 2: прежнее ограничение относится к преобразованиям строк бинарных матричных алгоритмов.

Эталон: верхние ячейки `(2,0,1,3)`, `(4,0,2,1)`, `(2,0,1,3)`. Нижние результаты `(2,0,1,3)`, `(4,1,1,2)`, `(3,1,0,0)`. Ответ `3α³+α²`. Первый сдвиг `(2,0,1,3,0)` сокращается вычитанием `(2,0,0,4,4)`; сырой результат `(0,0,1,−1,−4)` даёт `(1,4,1)`. После сложения с верхней ячейкой получается `(4,1,1,2)`. Второе сокращение использует 4M ≡ `(4,0,0,3,3)`.

Проверка выполняется независимой свёрткой A·B и последовательным приведением по M. Тесты сверяют 720 малых случаев с отдельной реализацией на Int, проверяют инвариант Горнера каждого столбца, точный конспект, выбор множителя, внутренние нули, константы, нулевые многочлены, предварительное приведение, отрицательные и 201-значные коэффициенты, ошибки ввода и отмену.


## Два режима оформления (27 октября 2026)

Подробный режим сохраняет существующий полный след вычислений. Режим «Как в конспекте» использует тот же результат и следующие шаблоны:

- Целочисленное удвоение–сложение: обе цепочки перевода с `>>`, двоичные записи, таблица с пустой верхней и нижней ячейкой 2 в первом столбце. Удвоение задаётся этим столбцом, в остальных ячейках числа и сложения/вычитания в столбик; добавление нуля не дублируется. Дополнительные разделы и объяснение выбора множителя скрыты.
- Двоичное деление: исходные двоичные длины, l и l−1, цепочка с `<<` до максимального допустимого сдвига, рекуррентная цепочка дробей, ответ a=bq+r. Повторное определение длин на каждом шаге и проверки соседних степеней скрыты.
- Матричные модульные методы: цепочка матриц с обозначениями преобразований, без номеров шагов и вычислений под матрицами. В методе 2ᵏ после первой полной матрицы выводится только первая строка, степени двойки сохраняются. В прямом делении все три строки и условие ≤ остатка числителя показаны в каждом состоянии. Подъём — строки сравнений по очередным модулям, как в PDF. Для найденного обратного отдельная предварительная проверка НОД скрыта; при отсутствии обратного сохраняется короткое обоснование через НОД.
- Многочлены: формула задачи, векторы коэффициентов, таблица с `(1,0)` слева и нормализованными вычитаниями/сложениями. Отдельная подготовка верхних ячеек, сырые отрицательные коэффициенты и комментарии о приведении по p скрыты.

Последние уточнения пользователя о приоритете деления, немедленном накоплении подходящей строки и допустимых множителях имеют преимущество над сокращениями/неточностями на фотографиях. Для входов, не представленных образцами (например, исходных отрицательных чисел), оставляются короткие необходимые коррекции знаков и представителей; подробные доказательства доступны в первом режиме. При больших исходных значениях предварительное приведение показывается одной строкой сравнения. Переключение меняет только представление и не пересчитывает ответ.


## Алгоритм Чиполлы (27 октября 2026)

Источник оформления: фотографии IMG_0772, IMG_0774, IMG_0775, IMG_0776 пользователя. Задача x² ≡ a (mod p), по умолчанию a=29, p=109. Математическая формула сверена с [G. Tornaría, Square Roots Modulo p, §3](https://www.cmat.edu.uy/~tornaria/pub/Tornaria-2002.pdf). Для невычета d=δ²−a вводится ω²=d; корни вычисляются как ±(δ+ω)^((p+1)/2).

Модуль проверяется точно для 2≤p≤2⁶⁴−1, составной отклоняется. Применяется детерминированный тест Miller–Rabin с основаниями 2, 325, 9375, 28178, 450775, 9780504, 1795265022; граница и основания опубликованы в [таблице детерминированных оснований](https://miller-rabin.appspot.com/). Вычисления UInt64 используют полное произведение 128 бит и деление полной ширины без переполнения. За пределами диапазона выдаётся явная ошибка, а не вероятностное утверждение о простоте. Подкоренное число a и ручное δ могут иметь любую длину и знак; сначала приводятся по p.

Для нечётного p и ненулевого a вычисляется символ Лежандра. В следе показаны вынесение −1, дополнительный закон для двойки, приведение числителя по знаменателю и квадратичная взаимность. Промежуточные составные знаменатели трактуются как символы Якоби, что сохраняет корректность взаимности; исходный символ имеет простой знаменатель. Значение −1 завершает задачу без корней. При a=0 возвращается единственный корень 0. Для p=2 возвращается a mod 2.

Автоматический поиск δ идёт от 0 до первого значения, для которого (δ²−a / p)=−1; все попытки сохраняются. Если символ равен 0, δ уже является корнем, расширение не строится. Ручное δ нормализуется; ненулевой вычет отклоняется с объяснением. Для d выбирается представитель минимального модуля (в примере −13 вместо 96). Элемент u+vω хранится парой коэффициентов, каждый от 0 до p−1. Произведение пар: (u+vω)(r+sω)=(ur+vsd)+(us+vr)ω. Для квадратов используется u²+v²d+2uvω. Скалярные произведения показаны отдельно; если требуется модульное приведение и оба множителя по модулю больше 2, сохраняется полный прежний след удвоения–сложения. Короткие произведения отображаются равенствами.

Показатель e=(p+1)/2 переводится в двоичную систему стандартной цепочкой. Вычисляются степени 1,2,4,8… до старшего разряда. Выбранные степени идут по убыванию показателя и перемножаются соседними парами, как в последней строке доски. Пример: (32·16)(4·2)(1) → (48·6)(1) → (54·1). Каждый узел дерева содержит операнды, все скалярные расчёты и результат. В конце коэффициент при ω обязан равняться 0. Оба корня проверяются независимым целым возведением в квадрат и делением с остатком.

Эталон с пары:

- (29/109)=1; значения δ=0,1,2,3 дают вычеты −29,−28,−25,−20; δ=4 даёт невычет −13.
- ω²=−13; e=55=110111₂=32+16+4+2+1.
- Степени: 4+ω; 3+8ω; 49+48ω; 26+17ω; 80+12ω; 59+67ω.
- Первая пара: (59+67ω)(80+12ω)=45+73ω.
- Вторая пара: (49+48ω)(3+8ω)=60+100ω.
- Далее (45+73ω)(60+100ω)=14+51ω; (14+51ω)(4+ω)=47+0ω.
- Ответ: 47 и 62. Проверка: 47²=2209=109·20+29, 62²=3844=109·35+29.

Оформление использует один студенческий лист. Основные математические переходы записаны без поясняющих заголовков; вычисления символов, полный двоичный перевод и подробная арифметика коэффициентов вынесены в отдельные окна. Формулы показателей сохраняются настоящими дробями; отрицательные представители и исправление знака доступны внутри соответствующего расчёта. Корни и независимая проверка завершают основной лист.

Тесты: точный эталон всех степеней и парных произведений; корни всех малых задач сверены с полным перебором; символы сверены с критерием Эйлера; проверены инварианты всех произведений пар и скалярных таблиц, большие a, почти максимальный 64-битный простой p, составные псевдопростые числа, ноль, p=2, ручное δ, ошибки и отмена.

### Пояснения по нажатию и вынесенные вычисления Чиполлы

Чиполла использует единый лист математической записи без переключателя режимов. На нём остаются условие, простота p, результат проверки символа, все попытки δ, определение ω², формула корней с дробным показателем, двоичное разложение, последовательные квадраты, попарные произведения, корни и проверка. Цепочки символов Лежандра/Якоби, полный двоичный перевод, раскрытие скобок и скалярные произведения открываются по ↗ в отдельных окнах; из произведения доступны вложенные таблицы удвоения–сложения. ? объясняет каждую строку; математические термины открывают определения. Закрытие окна сохраняет решение и положение прокрутки.

Для каждого множителя (−1) сохраняются исходная дробная формула показателя, её численная подстановка и целый результат. В цепочке показывается дробь, а по нажатию — правило, подстановка и влияние чётности на знак. В частности, при (29/109) взаимность даёт (108·28)/4=756. Для двойки сохраняется k(n²−1)/8, для −1 — (n−1)/2. Эти дроби проверены на точную делимость. Показатель корня показан в виде (p+1)/2 рядом с его значением. Подсказки также объясняют δ, отрицательный представитель ω², последовательные квадраты, выбор степеней по двоичной записи, сборку коэффициентов и второй корень p−t.

## Берлекэмп–Рабин: лекция 8, 27 октября 2026

Источник образца: предоставленный PDF «лекция 8», стр. 1–3. Проверка общей схемы: [MIT, Finite field arithmetic, §3.10](https://math.mit.edu/classes/18.783/2025/LectureNotes3.pdf). Речь о поиске всех корней в простом поле, а не о полной факторизации на произвольные неприводимые множители.

Ввод: целые коэффициенты f от старшей степени к свободному члену и простое q от 2 до 2⁶⁴−1; коэффициенты произвольной длины и знака. Составные q и расширения полей q=pᵐ не поддержаны. Проверка простоты точно использует прежний Prime64. Коэффициенты приводятся по q; ненулевой многочлен нормируется умножением на обратный старший коэффициент. Нулевой многочлен даёт всё поле, ненулевая константа — отсутствие корней. При q=2 подставляются 0 и 1.

Для нечётного q сначала проверяется f(0). При нулевом свободном члене выносятся все множители x: нулевой корень сохраняется один раз. У оставшегося нормированного F ненулевой свободный член. Вычисляется r=x^(q−1) mod(F,q), затем g=gcd(F,r−1). Это эквивалентно универсальному выделению gcd(f,x^q−x), с отдельной обработкой нуля, и сохраняет все различные ненулевые корни. Степень F может быть не меньше q.

g=1 означает отсутствие ненулевых корней. Для линейного нормированного g=x+c корень −c mod q. Для степени больше 1 перебирается δ=0,1,2,…; s=(q−1)/2; вычисляется h=gcd(g,((x+δ)^s mod g)−1). Разделение успешно только при 0<deg h<deg g. В частности, условие h≠1 в лекции дополнено исключением h=g. Точное частное g/h и h обрабатываются независимо, пока не останутся линейные множители. Перебор воспроизводим, не случаен; вероятностная оценка времени случайного алгоритма ему не приписывается. Все циклы отменяемы.

НОД хранит все деления и нормирования. Ненулевые остатки разрешено приводить к старшему коэффициенту 1 перед продолжением Евклида. Бинарная цепочка степени рекурсивная: 6→3→1, вычисленные показатели 1,2,3,6. Поэтому пример сохраняет переход x³ к x⁶, как в лекции. Полные произведения по запросу раскрываются прежним алгоритмом удвоения–сложения для многочленов.

Эталон: f=x³+3x²+2x+1, q=7; f(0)=1. x³≡4x²+5x+6; x⁶≡2x²+4x+2; x⁶−1≡2x²+4x+1≡2(x²+2x+4). Первый остаток Евклида при делении f на x²+2x+4 равен 3x+4; 5(3x+4)≡x+6. Следующее деление имеет частное x+3 и нулевой остаток. НОД x+6 даёт x≡−6≡1, f(1)=7≡0. Ответ [1]₇. Разделение сдвигами в этом примере не нужно, но реализовано для задач с несколькими корнями.

Представление: один лист без «Подробно / Как в конспекте» и без заголовков шагов. В основных равенствах сразу стоят результаты вспомогательных операций. Ссылки на аргументы НОД открывают вычисление степени или деления уголком в другом окне; знак вопроса даёт обоснование конкретной строки. Математические термины в пояснениях и словаре открывают определения. Последний ответ содержит классы всех целых решений, повторные корни не дублируются.

Тесты: точные все остатки, частные и нормирования лекции; случаи h=g и h=1 до успешного сдвига; несколько уровней разделения; 360 независимых малых задач с перечислением всех остатков; нулевые и повторные корни; степень не меньше q; константы, q=2, огромные коэффициенты и 64-битное простое q; ошибки и отмена. Проверены тождества делений, сохранение степеней и независимая проверка корней Горнером.

## Дополнение: новые алгоритмы

Для xⁿ≡a, n∈{2,3}, n∣p−1: сначала a^((p−1)/n)=1. Пишем p−1=nˢr, (n,r)=1, выбираем 1≤k<n с kr+1≡0 mod n. α=a^(kr). Для невычета b, ε=b^((p−1)/n) имеет порядок n. При ord(α)=nʲ выбираем i так, что α^(n^(j−1))εⁱ=1, заменяем α←αb^(ir n^(s−j)), c←c+ir n^(s−j−1). Порядок строго уменьшается. После α=1 берём x₀=a^((kr+1)/n)bᶜ; все корни x₀εᶦ. Если (n,p−1)=1, показатель корня — обратный к n по p−1. Нулевой элемент и характеристика n обрабатываются отдельно.

Для порядка по m=∏pᵉ: на простом p удаляем простой делитель d из кандидата t=p−1 только при a^(t/d)=1; при подъёме модуль увеличивается в p раз, порядок сохраняется либо умножается на p по результату проверки. Ответ — НОК локальных порядков. Простота множителей и произведение разложения проверены, окончательная степень проверяется независимо.

При обращении многочлена каждая строка (v,c) удовлетворяет v≡cA mod(M,p). Если M(0)≠0 и v(0)=0, сначала c←c−[c(0)/M(0)]M, затем оба многочлена делятся на α. Иначе сокращаются младшие коэффициенты, либо старшие с подходящим сдвигом. Для M(0)=0 деление на α не применяется. Последняя ненулевая константа d нормирует c умножением на d⁻¹; отсутствие константного НОД означает отсутствие обратного.
